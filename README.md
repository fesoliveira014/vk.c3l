# vk.c3l

Vulkan 1.3 core bindings for the [C3](https://c3-lang.org) language, generated
from Vulkan-Headers v1.4.317 (header version 317).

Generated from the Khronos `vk.xml` registry. Binding conventions: single `module vk;`,
`snake_case` functions with `@cname`, prefix-stripped `PascalCase` types, `try_`-prefixed
fault-returning command wrappers.

Forked/retargeted from [tonis2/Vulkan.c3](https://github.com/tonis2/Vulkan.c3).
Regenerated by [vk-gen](https://github.com/fesoliveira014/vk-gen).

## Use (git submodule)

```sh
git submodule add https://github.com/fesoliveira014/vk.c3l lib/vk.c3l
```

Then in `project.json`:

```json
"dependency-search-paths": [ "lib" ],
"dependencies": [ "vk" ]
```

Linked libraries are declared per-platform in `manifest.json`
(`:libvulkan.so.1` on Linux, `vulkan` on macOS, `vulkan-1` on Windows).

After instance creation, call `vk::load_extensions(instance)` before using any
WSI/extension entry points.
